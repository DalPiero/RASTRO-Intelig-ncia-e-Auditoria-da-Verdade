# RASTRO-Intelig-ncia-e-Auditoria-da-Verdade
RASTRO é uma plataforma de inteligência e auditoria de declarações públicas. Transcreve áudios e vídeos, identifica falantes, analisa discursos em 20 categorias e pesquisa evidências em fontes nacionais e internacionais. Combate a desinformação com método científico, transparência e rigor documental.
